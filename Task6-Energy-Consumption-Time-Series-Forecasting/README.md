**Project Overview**

This project forecasts household energy consumption using historical electricity usage data. Three forecasting models (ARIMA, Prophet, and XGBoost) were implemented and compared to determine the most effective approach for short-term energy prediction.

Dataset

The Household Power Consumption Dataset contains measurements of electric power consumption collected over several years at one-minute intervals.

Approach
Data Cleaning and Preprocessing
Time Series Resampling
Feature Engineering
ARIMA Forecasting
Prophet Forecasting
XGBoost Forecasting
Performance Evaluation using MAE and RMSE
Forecast Visualization
Results

The models were evaluated using MAE and RMSE metrics. XGBoost generally provides better predictive performance because it captures nonlinear relationships and engineered temporal features effectively.

Skills Demonstrated
Time Series Forecasting
Feature Engineering
Machine Learning
Statistical Modeling
Data Visualization
Conclusion

The project successfully forecasted household energy consumption and compared three forecasting techniques. XGBoost achieved the best overall performance, while ARIMA and Prophet provided useful baseline forecasting results. The study demonstrates how time-based features can improve forecasting accuracy in energy management systems.
